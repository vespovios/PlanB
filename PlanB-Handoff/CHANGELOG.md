# PlanB handoff changes

## Draft v0.3 — 5 October 2026

Purpose: incorporate Peter's supplied MagicStoryboard-inspired design summary into a staged, editor-independent planning product.

- Added a Cards view sharing the timeline's scene order, richer expandable scene details, optional thumbnails and draft/ready planning status independent of shot capture.
- Added optional image/link references and one storyboard per scene, with a simple drawing popup, editable document and matching PNG preview. Included touch use, private asset storage, revision checks and asset-aware backup/restore.
- Separated optional voice-over intent/text from audio/music intent. Retained scene purpose, checklist, location/context and general/edit notes.
- Added a portable JSON/Markdown/assets handoff as part of Delivery A. Preserved the canonical planning model independently of any NLE.
- Documented Delivery B for timed storyboard preview, with optional TTS/music after a basic playback trial, and Delivery C for independently validated editor adapters. Added OTIO limitations and real-import acceptance criteria using official documentation checked on 5 October 2026.
- Updated the coding instructions, agent workflow and first-delivery acceptance checks. Added VISUAL-PLANNING.md.
- Preserved both original visual references byte for byte. The interface image remains the earlier timeline reference; this revision does not claim that new screens have been visually approved.

The new scene fields, drawing and reference system, Cards view and portable handoff belong to the recommended first delivery. Preview and native NLE adapters are explicitly later work. Camera/subject icon libraries, additional attachment types, multiple storyboard panels per scene, bidirectional NLE sync, raw-media editing and finished-video rendering are not first-delivery requirements.

The supplied summary is used as design input; this revision does not claim an independent audit of MagicStoryboard's current product or editor compatibility.

## Draft v0.2 — 4 October 2026

Purpose: incorporate the focused recommendations from the Story Starter Kit review while keeping the original lightweight app design.

- Added one optional multiline story-outline field inside the episode brief area. A five-beat starter is optional and editable; the timeline remains unconstrained.
- Clarified how existing scene purpose, description, shot checklist and sound/narration notes connect a story idea to practical coverage. Brief editing intentions can use the existing notes.
- Added AGENT-WORKFLOW.md for finding a story, building scenes, reviewing human edits and revising around reported events. It preserves unknown outcomes and distinguishes captured footage from reviewed usable footage.
- Added mobile and agent access requirements for the outline and focused acceptance checks for the new field and workflow.
- Updated START-HERE.md and the coding prompt to reference the new guidance and identify this bundle as the current build brief.
- Preserved both original visual references byte for byte.

This revision does not add embedded chat, a separate journal application, a paid-course library, media management, video editing, offline sync or editor-project export. Notes from a trip can use the existing loose-notes field. The original timeline, checklist, VPS login, mobile support and authenticated external-agent connection remain the core build.

The review covered the supplied offline course text, seven PDF worksheets/guides, representative document layouts and the Resolve template's sequence structure. Video walkthroughs and native editor playback were not reviewed. The course's underlying planning ideas informed original PlanB guidance; its PDFs and media are not bundled.
